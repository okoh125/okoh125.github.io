# Fortune Okoh — Software Developer Portfolio

A polished, responsive portfolio website built for **Assignment #3 — Portfolio Website**, hosted on **GitHub Pages**. No installation, database, backend, Node packages, or build step is required.

Live Website: https://okoh125.github.io

## Included files

- `index.html` — all website sections and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and project filters
- `assets/favicon.svg` — portfolio tab icon
- `assets/Fortune_Okoh_Resume.pdf` — downloadable resume
- `.nojekyll` — publish these static files without Jekyll processing

## Run locally

1. Open the folder in VS Code.
2. Open `index.html` in a web browser, or install **Live Server** in VS Code, then right-click `index.html` → **Open with Live Server**.
